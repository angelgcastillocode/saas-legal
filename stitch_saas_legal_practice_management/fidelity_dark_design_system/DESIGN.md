# Design System - Fidelity Dark

## Brand & Style
The design system embraces a modern, professional, and reliable aesthetic with a **Corporate / Modern** style. Built specifically for an immersive **dark color mode**, it relies on crisp typography, high-precision layout grids, and a sophisticated color palette designed to reduce eye strain while maintaining excellent visual hierarchy and clarity.

## Colors
- **Primary (`#1275e2`)**: Vibrant blue for primary actions and active states.
- **Secondary (`#5f78a3`)**: Slate blue for secondary elements and supportive UI structures.
- **Tertiary (`#c55b00`)**: Burnt orange for focal highlights and warnings.
- **Neutral (`#74777f`)**: Balanced cool gray for typography, borders, and surfaces.

## Typography
The entire interface relies on the **Inter** font family for headlines, body text, and labels, ensuring an exceptionally clean and legible user experience across devices.

## Layout & Spacing
Built on a fluid layout grid with a standard `1.5rem` outer margin and `1rem` gutters, using a consistent modular spacing scale.

## Elevation & Depth
Depth is achieved through tonal surface differentiation and subtle contrast layers, avoiding heavy drop shadows in favor of modern dark-mode layering.

## Shapes
Components feature high roundedness (pill-shaped, level 3), giving interactive elements soft, approachable curves.

## Components
Consistent styling applied to buttons, input fields, cards, and chips using the primary color tokens and pill-shaped geometry.
